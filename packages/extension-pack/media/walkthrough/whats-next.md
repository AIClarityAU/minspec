# What's next in the pack

A third extension, **agent-execute** (tiered separately from MinSpec's air-gapped core),
is planned for agent dispatch but isn't part of this pack yet — it isn't installed by
MinSpec Pro today, and nothing here activates it early.

When it lands, this orientation walkthrough is the place a new step for it gets added —
not a reason to duplicate MinSpec's or ScroogeLLM's own walkthroughs here in the meantime.
