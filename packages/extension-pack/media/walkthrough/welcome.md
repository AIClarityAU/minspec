# Welcome to MinSpec Pro

MinSpec Pro is an **extension pack** — it installs a small set of extensions together and
orients you across them. It has no features of its own; everything you do happens inside
the extensions it bundles.

## What's in the pack today

| Extension | Domain | What it's for |
|---|---|---|
| **MinSpec** | Specification-Driven Development | Classify tasks by tier, write just enough spec, track phases |
| **ScroogeLLM** | LLM cost measurement | Tee-proxy, shadow classifier, and safe-cut instruments — not a billing/GTM product right now |

This walkthrough doesn't repeat what each extension already teaches — it points you to
their own "Get Started" walkthroughs so you land in the right place.
